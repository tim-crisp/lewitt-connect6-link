# Changelog

## 1.3.0

- Universal macOS 13+ application for Intel and Apple Silicon.
- Portable CONTROL CENTER discovery by bundle identifier.
- Public application identifier, original app icon and MIT license.
- Drag-to-Applications DMG, checksums and installer verification.
- GitHub Actions tests/builds for both Mac architectures on master.
- Tag-triggered GitHub releases, optional Developer ID signing and Apple
  notarization, with explicit signing status in release notes.

Existing controls include linked output volumes, independent mutes, Mobile in
Mix A/B send controls with 0 dB reset, and Mac volume-key target activation.
