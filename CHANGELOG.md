# Changelog

## 1.0.0 — 2026-11-06

First public release.

- Native macOS menu bar controls for LEWITT CONNECT 6 firmware 2.2.7.
- Linked output volumes with relative and equal-dB modes.
- Independent speaker/headphone mutes and group volume/mute controls.
- Mobile in Mix A/B send levels, mutes and 0 dB reset buttons.
- Per-output activation for the Mac's system volume controls.
- Compact panel with all controls visible, automatic reconnection and optional
  launch at login.
- Universal macOS 13+ application for Intel and Apple Silicon.
- Portable CONTROL CENTER discovery, original app icon and MIT license.
- Drag-to-Applications DMG, SHA-256 checksums and installer verification.
- GitHub Actions tests/builds for both Mac architectures on master and
  tag-triggered releases, with optional Developer ID signing and notarization.
